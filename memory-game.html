Memory Game

Match pairs, train your memory and improve your best time

Memory Game is a free browser matching-pairs game with six themed sections, four difficulty levels, multilingual controls and saved progress. Choose a theme, reveal two cards at a time and find every matching pair using as few moves and as little time as possible.

ABOUT THE GAME

A memory challenge with several themes

Choose from Brain, Daily, Kids, Animals, Food and Travel. Each section uses a different set of symbols, while the core challenge stays the same: remember where the cards are and uncover matching pairs.

Difficulty levels

  • Easy — 6 pairs.
  • Medium — 8 pairs.
  • Hard — 12 pairs.
  • Expert — 15 pairs.

Game features

  • English, Croatian, German, Italian and Spanish interface languages.
  • Move counter, timer and best score for each category and difficulty.
  • Save & Exit and Resume Saved Game.
  • Exit Without Save and Play Again / Restart.
  • Fullscreen support in compatible browsers.
  • Responsive layout for desktop, tablet and mobile browsers.
  • Keyboard-accessible dialogs and accessible card labels.

How to play

Turn over two cards. If they match, they stay revealed; if not, they turn back over. Continue until every pair has been found. Try to finish with fewer moves and a faster time.

Play instantly
