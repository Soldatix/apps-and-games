Eine WLAN-QR-Karte für Gäste erstellen

Ermögliche vertrauenswürdigen Gästen den Zugang zum Gastnetz ohne Passworteingabe.

Schritt für Schritt

  1. Wähle beim ersten Öffnen bei Bedarf Deutsch im Sprachmenü der App. Wähle WLAN und gib den exakten Netzwerknamen (SSID), Sicherheitstyp und das Gastpasswort ein.
  2. Wähle QR-Code erstellen und dann PNG herunterladen oder SVG herunterladen.
  3. Teste den Code mit einem kompatiblen Smartphone und drucke eine kleine beschriftete Karte.

Beispiel

Beispiel: Erstelle eine Karte Gäste-WLAN für ein separates Gastnetz und lege sie ins Gästezimmer.

Tipp

Wer den Code scannt oder kopiert, kann die Zugangsdaten erfahren. Veröffentliche keinen privaten Netzcode; ersetze die Karte nach Passwortänderungen.
