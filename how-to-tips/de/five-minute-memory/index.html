Bildung & Lernen · Memory Game

Fünf Minuten täglich Paare suchen

Nutze eine kurze wiederholbare Spielrunde, um Positionen bewusst wahrzunehmen und abzurufen.

Schritt für Schritt

  1. Wähle in Memory Game ein Thema und einen Schwierigkeitsgrad für eine Woche.
  2. Verbinde beim Aufdecken das Symbol mit einer Reihe oder einer nahen Ecke.
  3. Spiele etwa fünf Minuten und vergleiche deine Versuche anhand von Zeit oder Zügen, soweit angezeigt.

Beispiel

Beispiel: Merke dir den Apfel oben links und die Tasse unten rechts, statt auf dem ganzen Feld zu raten.

Tipp

Ändere nur eine Schwierigkeitseinstellung gleichzeitig. Spielfortschritt beweist keinen medizinischen oder allgemeinen Gedächtnisnutzen.
