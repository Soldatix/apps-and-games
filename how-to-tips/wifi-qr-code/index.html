Make a Wi-Fi QR card for your guests

Let trusted visitors join a guest network without typing its password.

Step by step

  1. On first use, select English in the app’s language menu if needed. Choose Wi-Fi and enter the exact network name (SSID), security type and guest password.
  2. Select Generate QR code, then Download PNG or Download SVG.
  3. Test the code with a compatible phone and print a small card with a clear label.

Example

Example: create a card marked Guest Wi-Fi for a separate guest network and place it in the guest room.

Tip

Anyone who can scan or copy the code can learn the Wi-Fi credentials. Do not publish your private network code; replace the card when the password changes.
