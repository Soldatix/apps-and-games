Educación y aprendizaje · Memory Game

Practica las parejas cinco minutos al día

Usa una sesión breve y repetible para practicar la observación y el recuerdo de posiciones.

Paso a paso

  1. Elige un tema y dificultad en Memory Game y mantenlos durante una semana.
  2. Al descubrir una carta, asocia el símbolo con una fila o una esquina cercana.
  3. Juega unos cinco minutos y compara tus intentos por tiempo o movimientos, si se muestran.

Ejemplo

Ejemplo: recuerda la manzana arriba a la izquierda y la taza abajo a la derecha en lugar de adivinar por todo el tablero.

Consejo

Cambia solo un ajuste de dificultad cada vez. Mejorar en el juego no demuestra beneficios médicos ni generales para la memoria.
