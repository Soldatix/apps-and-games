Understand your internet speed test results

Download, upload and latency

Download speed (Mbps) describes how quickly data reaches your device, for example during video streaming or file downloads. Upload speed matters when sending files or sharing video on a call. Latency, usually reported in milliseconds (ms), describes response delay: lower values generally help interactive applications and online games.

Is the problem Wi-Fi or the internet connection?

Run a test near your router, then repeat it where you normally use your device. If possible, compare both results with a wired Ethernet test on the same connection. Use the same test conditions, pause other network activity and record several results. A slow Wi-Fi result alone does not establish that your internet provider is at fault.

Mbps is not the same as MB/s

Network speeds are usually shown in megabits per second (Mbps), while file downloads may use megabytes per second (MB/s). Divide Mbps by eight for a theoretical decimal MB/s value: 100 Mbps corresponds to 12.5 MB/s before protocol overhead and other limitations. Actual download speeds may be lower.

Check mobile coverage separately

If you use a phone, compare tests on Wi-Fi and mobile data separately, and note the location and time. Coverage maps can help you compare reported 4G and 5G coverage, but cannot guarantee the speed inside your building. Speed tests can consume mobile data.

Results are a snapshot, not a guarantee of your subscription speed. Device capability, Wi-Fi interference, network load and the test server can affect measurements. Compare multiple readings before drawing conclusions.

Tips for reliable results

Stop large downloads and uploads on your devices, close unnecessary streaming apps and try another measurement at a different time. Wi-Fi speed may differ from a wired connection.
