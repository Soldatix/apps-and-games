English

Windows Installer and Screen Saver

The standard Windows Installer provides a separate Windows .scr Screen Saver. Activation is optional and off by default; it does not require enabling the Screen Saver during installation. Unlike the Portable edition, the Windows installer can integrate it with Windows Screen Saver settings. Its moving clock reduces prolonged static content but cannot guarantee prevention of OLED burn-in. Do not remove your existing edition or backups when changing versions.

The previous .NET Installer is being replaced by a Rust edition. The Installer download is temporarily unavailable until the release and license reviews are complete.

Digital Clock Windows Portable — v0.3.8

Download Windows Portable ZIP

  1. Download the Portable ZIP from GitHub and extract all files into a writable folder.
  2. Run digital-clock-rust-portable.exe from the extracted folder (not from inside the ZIP).
  3. Keep vcruntime140.dll beside the EXE and retain the NOTICES folder.
  4. Settings and backups are saved in Data; preserve that folder when updating.
  5. Windows SmartScreen: if you see Windows protected your PC, first verify the ZIP came from our official GitHub Release and its SHA-256 matches the value below. Then select More info → Run anyway. If you cannot verify the file, select Don't run.

Note: No installation or WebView2 is needed. The built-in screensaver works inside the app; it is not a Windows .scr screensaver.
