English

Windows 10/11 x64 — version 2.0.5

Download Windows Installer Download Portable ZIP

Standard Windows installation

  1. Download DigitalClock-Setup-x64.exe from the official Apps & Games download domain.
  2. If Windows shows Windows protected your PC, click More info, then Run anyway. Continue only if the file came from our official domain and its SHA-256 matches.
  3. Choose the setup language. By default, the app installs for the current user only.
  4. The Digital Clock Screen Saver activation option is unchecked by default.
  5. The installer installs or updates Microsoft Edge WebView2 Runtime when needed.
  6. After setup, launch Digital Clock. Bedside mode can be exited with Esc.
  7. Future updates can be checked in Info → Windows update.

SmartScreen: the Windows release is not yet digitally signed, so Windows may display Unknown publisher. Run only files downloaded from downloads.appsandgames.org and verified with SHA-256.

Installer SHA-256: AF549F479F01EBACE212A826F0FF8775AEC5E787912B3F6C84E784F19DE5B4E1

Portable edition — no installation

  1. Download DigitalClock-Portable-x64.zip from the official Apps & Games download domain.
  2. Right-click the ZIP and choose Extract All.
  3. Move the extracted folder anywhere you want, including another drive or USB drive.
  4. Open the extracted folder and run DigitalClock.Windows.exe. Do not run the EXE directly from the ZIP archive.
  5. If “Windows protected your PC” appears: Digital Clock is not yet digitally signed, so Microsoft Defender SmartScreen may show Publisher: Unknown publisher. If necessary click More info, then Run anyway. Continue only when the ZIP was downloaded from our official domain and its SHA-256 matches the published value.
  6. Portable settings and local data are stored in the local Data folder.
  7. The Windows Screen Saver is not included in the portable edition. Use the regular Windows installer for Screen Saver support.
  8. If Microsoft Edge WebView2 Runtime is missing, install the official Microsoft runtime.
  9. To update, close Digital Clock, replace the application files with the new Portable ZIP and keep the existing Data folder.

Important: the portable edition itself requires no installation. If you enable Start with Windows, Windows creates a startup entry for the current user.
