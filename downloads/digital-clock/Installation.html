English

Windows 10/11 x64 — version 2.0.5

Download Windows Installer Download Portable ZIP

Standard Windows installation

  1. Download DigitalClock-Setup-x64.exe (about 55 MB) from the official Apps & Games download domain.
  2. Run the installer. If Windows shows Windows protected your PC, click More info, then Run anyway. Continue only if the file came from our official domain and its SHA-256 matches.
  3. Choose the setup language. By default, the app installs for the current user only.
  4. The option to activate the Digital Clock Screen Saver is unchecked by default.
  5. The installer installs or updates Microsoft Edge WebView2 Runtime when needed.
  6. After setup, launch Digital Clock. Bedside mode can be exited with Esc or the exit button.
  7. Future updates can be checked in Info → Windows update.

Note: the Windows release is not yet digitally signed, so SmartScreen may show a warning and Unknown publisher. Continue only for files downloaded from downloads.appsandgames.org and verified with SHA-256.

Portable edition — no installation

  1. Download DigitalClock-Portable-x64.zip from the official Apps & Games download domain.
  2. Right-click the ZIP and choose Extract All.
  3. Move the extracted folder anywhere you want, such as Documents, another drive or a USB drive.
  4. Open the extracted folder and run DigitalClock.Windows.exe. Do not run the EXE directly from inside the ZIP archive.
  5. SmartScreen warning: because the EXE is not yet digitally signed, Microsoft Defender may display Windows protected your PC and Publisher: Unknown publisher. If necessary click More info, then Run anyway. Do this only when the ZIP was downloaded from our official domain and its SHA-256 matches the published value.
  6. The portable edition has the same interface and main Windows app functions. Settings and local data are stored in the local Data folder.
  7. The Windows Screen Saver is not included in the portable edition. Use the regular Windows installer if you want the Screen Saver.
  8. If Microsoft Edge WebView2 Runtime is missing, install the official Microsoft WebView2 Runtime and launch Digital Clock again.
  9. To update, close Digital Clock, download the newest Portable ZIP and replace the application files. Keep the existing Data folder.

Important: the portable edition itself requires no installation. If you manually enable Start with Windows, Windows creates a startup entry for the current user. Disable it before moving or deleting the portable folder.
