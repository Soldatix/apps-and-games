ABOUT THE APP

About Digital Clock

Digital Clock is a free customizable clock for Windows, Android and the web. Its clear time display is useful on a desk, across a room, or beside the bed.

Main features

  • Customizable time and date display, fonts, colors and fullscreen view.
  • Alarms, countdown timer, stopwatch and world clock.
  • Bedside mode and an in-app screensaver.
  • Local settings, backup and restore in Windows Portable.

Digital Clock Windows Portable

Download the ZIP for Windows 10/11 x64, extract every file, and run digital-clock-rust-portable.exe. No Windows installer or Microsoft Edge WebView2 is required. Keep Data when updating to preserve settings and backups.

The screensaver works inside the application; it is not a system Windows .scr screensaver. The Microsoft Store edition is a separate installed version.

Available platforms

Use Digital Clock as Web/PWA, Windows Portable, a separate Microsoft Store installation, or on Android.

Frequently asked questions

Is Digital Clock free? Yes.

Does the Windows Portable version require installation? No. Extract the ZIP and run the EXE.

Does the Windows Portable version include a screensaver? Yes, an in-app screensaver, not a Windows .scr screensaver.

Privacy and availability

No Apps & Games account is required. Settings are stored locally where supported. Read the Privacy Policy for website analytics and privacy information.
